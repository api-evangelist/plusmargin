## What an agent can and cannot do here

- There is **no product API**. api., app., developer., docs., dev. and portal.plusmargin.com are
  all NXDOMAIN. /openapi.json, /openapi.yaml, /swagger.json, /graphql, /api and /api-docs all 404.
- There is **no agent surface**. No /.well-known/agent-card.json, no /.well-known/agent.json, no
  MCP server, no ai-plugin.json, no api-catalog.
- There **is** one callable, machine-readable surface: the stock **WordPress REST API** at
  https://plusmargin.com/wp-json — 237 routes across 11 namespaces, self-identifying as
  "Plus Margin". Core content is anonymously readable. This is WordPress core's API, not a
  product PlusMargin designed, supports, or documents. Treat it as a content feed, not a
  supported integration surface.
- To reach the company, use the contact page. There is no developer support channel.

## WordPress REST API (third-party CMS surface, unsupported)

- Root discovery document: https://plusmargin.com/wp-json
- Content routes: https://plusmargin.com/wp-json/wp/v2 (posts, pages, categories, tags, types,
  users, media, search, comments)
- Pagination: `page` + `per_page` (max 100); `X-WP-Total` and `X-WP-TotalPages` response headers;
  RFC 8288 `Link` header with rel="next"/"prev"
- Sparse fieldsets: `?_fields=` — hypermedia embedding: `?_embed`
- Authentication: WordPress Application Passwords (HTTP Basic), authorize at
  https://plusmargin.com/wp-admin/authorize-application.php. Cookie + `X-WP-Nonce` for
  same-origin browser calls. No OAuth 2.0, no OpenID Connect.
- Errors: `{"code": "...", "message": "...", "data": {"status": nnn}}` as application/json.
  NOT RFC 9457 problem+json.
- Rate limits: none published, none signaled. No X-RateLimit-*, no Retry-After, no 429 observed.
- Idempotency: not supported. No Idempotency-Key.
- The WordPress **Abilities API** (`/wp-json/wp-abilities/v1/abilities`) is registered on this
  install but returns HTTP 401 `rest_forbidden` to anonymous callers, so no ability catalog or
  inputSchema can be introspected without credentials.
